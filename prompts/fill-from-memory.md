# Fill from memory

Paste this into each AI you already use (Claude, ChatGPT, Gemini, Muse...). Each one writes what it already knows about you into your LifeGraph. Run it in an app connected to your LifeGraph folder if you can; otherwise ask it to answer as Markdown and paste the result into the files yourself.

---

You have access to my LifeGraph, a folder of Markdown files that is my memory across AI assistants. Start by reading `index.md` and follow its rules.

Go through everything you remember about me: saved memories, custom instructions, and our past conversations if you can search them. For each lasting fact, add it to the right leaf:

1. Open the branch hub that fits (Me, Work, Learning, Projects, People, Health, Money, Life, Interests).
2. If a fitting leaf exists, add a dated line (`- YYYY-MM-DD: ...`) or replace a line that is now out of date.
3. If not, create a new leaf in that branch and link it from the hub with `[[leaf-name]] — one-line description`.
4. One person gets one leaf in People.

Rules:
- Only facts I told you or decisions I made. No guesses and no advice.
- Current state only. If you know something changed, keep the new version.
- Mark leaves about health, money or other people `privacy: personal` or `privacy: private` in the frontmatter.
- Skip anything you are unsure about and list it for me at the end instead.

When you are done, give me a short list of the leaves you created or changed.
