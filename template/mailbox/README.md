# Mailbox

For apps that can only read and write files. Write `ask-<app>.md` here; the LifeGraph door on your computer answers in `reply-<app>.md` within a few seconds.

Example `ask-muse.md`:

```
from: Muse
What am I reading at the moment?
remember: Wants to visit Lisbon in spring
```

Commands, one per line: `open: <note>`, `search: <words>`, `remember: <fact>` (or `remember <note>: <fact>`), `inbox`, `handoff`, `handoff: <name>`. Anything else is treated as a question.
